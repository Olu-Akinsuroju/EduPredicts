Researcher Portal

Welcome to the Researcher Portal. This section allows you to perform batch predictions on student datasets. You can upload a CSV file containing student information, and our system will process it to generate predictions for each student.

How it Works

  1. Prepare Your Data: Ensure your CSV file has the required columns. You can download a sample CSV template to see the expected format. The required columns are: Previous Grade, Absences, Study Time, Age, Internet Access (True/False), Extra Courses (True/False), Motivation (1-5), Parent Education (1-5).
  2. Upload CSV: Use the upload form to submit your data. You'll see a preview of the first 5 rows.
  3. Run Predictions: Confirm the preview and click "Run Predictions". The system will process the entire file.
  4. Download Results: Once processing is complete, you'll be able to download a CSV file containing the original data along with the added prediction columns.
